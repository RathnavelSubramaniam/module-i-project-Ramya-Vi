# 📈 News Sentiment Analysis for Stock Price Prediction

## Project Overview
This project analyzes financial news articles to determine their sentiment (positive, negative, or neutral) and uses that information to help predict stock price movements. The goal is to demonstrate how Natural Language Processing (NLP) and Machine Learning can assist investors in making better financial decisions.

---

## Business Problem
Stock prices are influenced by many factors, including:
- Company performance
- Economic conditions
- Market trends
- Financial news
- Investor sentiment

Analyzing thousands of news articles manually is difficult. This project automates sentiment analysis to extract useful insights that can improve stock price prediction.

---

## Objectives
- Analyze financial news articles.
- Determine the sentiment of each news article.
- Prepare the data for machine learning.
- Build prediction models.
- Evaluate model performance.
- Understand the relationship between news sentiment and stock prices.

---
